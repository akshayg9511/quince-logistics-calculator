Quince Logistics Calculator

Upload an Excel file. We compute Logistics Cost Ocean and Logistics Cost Air per row and return an Excel with two extra columns appended. Row order preserved.

Input requirements

Your file must contain these exact column headers (case-insensitive) somewhere in rows 1–5:

  • Length (in)
  • Width (in)
  • Height (in)
  • Weight (g)
  • COO — accepts IN, India, India | IN, or System default (India)

Rows above the header (banner, labels, instructions) are dropped from the output. Data is everything below the header row.

Rows with missing or invalid values are kept in the output with blank Ocean/Air and an explanation in a new Notes column — no row blocks the rest of the file.
